# Grow Up Music Entertainment

Website resmi Grow Up Music Entertainment - Jasa band profesional untuk wedding, corporate event, cafe & restaurant di Jakarta dan Bekasi.

## 🎵 Tentang Kami

Grow Up Music Entertainment adalah penyedia jasa hiburan musik profesional yang melayani berbagai acara seperti:
- Wedding & Reception
- Corporate Event
- Cafe & Restaurant Entertainment
- Private Party
- Grand Opening

## 🎸 Format Musik

- **Full Band** - Formasi lengkap dengan semua instrumen
- **Band Akustik** - Nuansa hangat dan intim
- **Solois Akustik** - Penampilan solo yang personal

## 🚀 Teknologi

Website ini dibangun menggunakan:
- **Vite** - Build tool yang cepat
- **React 18** - Library UI modern
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - Komponen UI yang elegan
- **Lucide React** - Icon library

## 📦 Instalasi & Development

```bash
# Clone repository
git clone https://github.com/bagussundaru/GrowUP.git
cd GrowUP

# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build untuk production
npm run build

# Preview build
npm run preview
```

## 🌐 Deployment

Website ini dapat di-deploy ke:
- **Vercel** (Recommended)
- **Netlify**
- **GitHub Pages**
- **Firebase Hosting**

### Deploy ke Vercel

1. Push code ke GitHub
2. Connect repository di Vercel
3. Deploy otomatis akan berjalan
